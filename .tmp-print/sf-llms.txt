# Specialist Factory

> Fix the weak LLM under your agent — basically free.

Specialist Factory manufactures **task models**: small open-weight models trained on your proprietary outcomes for one scoped job (fraud, triage, routing, review), then called by your existing agent or harness.

We are **not** a specialist-agent product, agent platform, RAG platform, or frontier API. Agent ≠ model — we sell the model under the agent.

## Stack

```
Your agent / harness
 │ calls
 ▼
Task model (open weights + your labeled outcomes)
 │ runs on
 ▼
Shared cloud · Your cloud (BYOC) · Confidential GPU
```

## Beachhead

Teams that already have an agent on one labeled, high-volume job and are stuck because the frontier LLM is too expensive, flaky, or unsafe with proprietary data.

## Trust ladder

- Shared cloud — Pilot / multi-tenant
- Your cloud (BYOC) — proprietary data default
- Confidential GPU — NVIDIA CC + attestation
- On-prem — deferred (do not offer)

## Pricing

- Pilot: $0 / $50 training credits (Shared)
- Build: $499/mo (BYOC, up to 10 task models)
- Scale: $2500/mo (Confidential GPU, SSO)
- Enterprise: custom
