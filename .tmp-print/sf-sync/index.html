What is a task model?

A task model is a small open-weight model trained on your labeled outcomes for one scoped job — fraud, triage, routing, review — then called by your existing agent or harness. Specialist Factory manufactures task models; we do not sell the agent.

Is a task model a specialist agent?

No. A specialist agent is an agent product. A task model is weights under your agent. Keep the harness and tools; swap only the weak frontier LLM call for that one labeled job.

Is Specialist Factory an agent platform?

No. We do not build or replace LangChain, CrewAI, or your orchestration. Your agent calls our task-model endpoint. Agent ≠ model — we sell the model.

When should I use a task model instead of a frontier LLM?

When you already have a high-volume, labeled decision in an agent loop and the frontier model is too expensive, flaky, or unsafe with proprietary data. Open-ended work can stay on frontier.
